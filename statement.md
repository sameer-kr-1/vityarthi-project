# Project Statement – AttendTrack

## Problem Statement
Tracking student attendance manually is time-consuming and error-prone. Teachers need a simple system to record daily attendance, calculate attendance percentages, identify students with low attendance, and generate reports.

AttendTrack solves this problem by providing a console-based Python application that enables easy student registration, attendance marking, and analytical reporting.

## Scope of the Project
**In Scope:**
- Student registration and management (CRUD)
- Marking attendance (Present / Absent) for any date
- Individual and class-wise attendance reports
- Identification of students with attendance below 75%
- Data persistence using JSON
- Input validation

**Out of Scope:**
- Graphical User Interface
- Multi-user login / authentication
- SMS / Email notifications
- Advanced database systems
- Web or mobile application

## Target Users
- Teachers and class coordinators
- Students learning programming concepts
- Anyone needing a lightweight offline attendance system

## High-level Features
1. **Student Management Module** – Add, view, update, delete student records
2. **Attendance Marking Module** – Mark Present/Absent for single or all students
3. **Reports Module** – Individual reports, class summary, low attendance alerts, search
4. **Data Persistence** – Automatic saving and loading of records
5. **Modular Design** – Clean separation into multiple Python files
